# `outline.json` 格式

## 顶层字段

```json
{
  "title": "课程名（通俗版）",
  "subtitle": "自学者友好 · 基于老师课件改写",
  "output": "课程名（通俗版）.pptx",
  "slides": [],
  "page_coverage": {},
  "homework_map": []
}
```

- `slides`：新 PPT 的页面数组。
- `page_coverage`：原课件逐页归宿。键为原页码，值至少包含 `status`、`destination` 与 `reason`。
- `homework_map`：有作业题时使用，每项包含 `question`、`topics`、`source_pages`、`output_slides`。

## 页面类型

### 封面 `cover`

```json
{"type":"cover"}
```

标题和副标题从顶层字段读取。

### 概念页 `concept`

```json
{
  "type": "concept",
  "title": "输入电阻为什么越大越好",
  "one_liner": "输入电阻大，信号源被分走的电压更少。",
  "exam": "掌握",
  "bullets": [
    "输入电阻 Ri（从输入端看进去的等效电阻）会与信号源内阻分压。",
    "Ri 越大，实际到达放大电路的输入电压越接近源电压。"
  ],
  "analogy": "像用量程合适的电压表测量，测量工具本身尽量少影响原电路。",
  "terms": ["输入电阻 Ri：从输入端看进去的等效电阻。"]
}
```

### 公式页 `formula`

优先通过 `source` 使用原页图。只有无法取得合适原图时才使用 `latex`，且必须对照原图核对。

```json
{
  "type": "formula",
  "title": "频率、周期与角频率",
  "source": "assets/pages/slide_032.png",
  "source_label": "原课件第32页",
  "note": "T 是重复一次所需时间；f 是每秒重复次数；ω 是每秒变化的相位弧度。",
  "exam": "必考",
  "terms": ["周期 T：信号重复一次所需时间。", "角频率 ω：每秒变化的相位弧度。"]
}
```

### 例题页 `example`

`source` 必填，必须指向原课件整页高清图。一道例题一页。

```json
{
  "type": "example",
  "title": "例题（原课件第50页）",
  "source": "assets/pages/slide_050.png",
  "source_label": "原课件第50页",
  "exam": "必考",
  "analysis": "这题考输入端分压和输出端带载。第一步先求真正到达放大电路的输入电压，因为源电压不一定全部加到输入端。最容易错的是把开路增益和带载增益混用。",
  "steps": [
    "先用信号源内阻和输入电阻求输入电压。",
    "再用开路增益求受控源电压。",
    "最后考虑输出电阻与负载的分压。"
  ],
  "terms": ["带载：输出端接上负载工作。"]
}
```

### 小结页 `summary`

```json
{
  "type": "summary",
  "title": "本章小结",
  "bullets": ["先辨认信号参数，再分析输入与输出连接。"],
  "terms": []
}
```

## 覆盖表与作业映射示例

```json
{
  "page_coverage": {
    "1": {"status":"retained", "destination":[1], "reason":"封面信息"},
    "2": {"status":"merged", "destination":[2], "reason":"并入课程路线概念页"},
    "9": {"status":"example", "destination":[12], "reason":"例题独立保留原页"}
  },
  "homework_map": [
    {
      "question": "1.4.1",
      "topics": ["输入分压", "输出带载"],
      "source_pages": [45, 46],
      "output_slides": [18, 19]
    }
  ]
}
```

生成前检查 `page_coverage` 是否覆盖从 1 到原课件总页数的所有页码。生成后更新 `destination` 为实际新 PPT 页码。
